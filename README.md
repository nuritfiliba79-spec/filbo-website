# פילבו מחסני היבואן — אתר תדמית

> **פילבו – ניסיון של דורות במטבח הישראלי**
> יבוא ושיווק כלי מטבח לבית, לעסקים ולמוסדות.

אתר תדמית סטטי בעברית (RTL) לחברת **פילבו**, עסק משפחתי ישראלי לייבוא ושיווק כלי מטבח שפועל משנות ה־30.

---

## אסטרטגיה

האתר אינו "עוד חנות כלי בית". הוא מדבר במקביל לשני קהלים:

| קהל | מה מחפש | איך האתר עונה |
|---|---|---|
| **לקוחות פרטיים** | כלי מטבח איכותיים, מחיר טוב, שירות | קטגוריות מוצרים, מחיר של יבואן, שירות אישי |
| **לקוחות עסקיים ומוסדיים** | ניסיון, אמינות, יכולת אספקה, מגוון גדול | עמוד מוסדי ייעודי, תהליך עבודה, FAQ רכש, הצעת מחיר |

הבידול המרכזי: **מורשת משפחתית אמיתית משנות ה־30** — משהו שמתחרים באינטרנט לא יכולים לחקות.

## עיצוב

- **צבעים:** אדום מותג `#C8102E`, אדום עמוק `#8A0B20`, לבן דומיננטי, קרם חמים `#FAF7F5` (אווירה משפחתית), פחם `#1A1A1A`.
- **טיפוגרפיה:** Rubik (תמיכה מצוינת בעברית) — כותרות, גוף ותוויות.
- **שפה ויזואלית:** מודרני ונקי, הרבה לבן, צילומי מוצר גדולים — **לא** מראה של "מחסן כלי בית".
- **RTL מלא:** `dir="rtl"` בכל העמודים, מאפייני CSS לוגיים (`inset-inline`, `margin-inline`, `padding-inline-start`).

## אלמנטים דינמיים

| אלמנט | מימוש |
|---|---|
| Ken Burns ב־Hero | אנימציית CSS על תמונת הרקע |
| חשיפה בגלילה | `IntersectionObserver` + `data-delay` להשהיה מדורגת |
| ספירת מספרים | אנימציית easing על `[data-count]` |
| סינון קטגוריות | `[data-filter]` / `[data-cat]` בעמוד המוצרים |
| Header דביק | הצללה נוספת לאחר גלילה (`.is-stuck`) |
| Hover על כרטיסים | הרמה, צל, סיבוב האייקון |
| אקורדיון FAQ | `<details>` נייטיב עם אנימציית `+` → `×` |
| תפריט מובייל | המבורגר עם `aria-expanded` |
| טופס | ולידציה + הודעת הצלחה (הדגמה בצד לקוח) |
| כפתור WhatsApp צף | קבוע בפינה בכל העמודים |

`prefers-reduced-motion` נתמך — כל האנימציות נכבות עבור משתמשים שביקשו זאת.
