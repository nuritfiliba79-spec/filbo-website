## תמצית מהירה

**מיצוב:** פילבו – ניסיון של דורות במטבח הישראלי. יבוא ושיווק כלי מטבח לבית, לעסקים ולמוסדות.

**שני קהלים:**
- לקוחות פרטיים — כלי מטבח איכותיים, מחיר טוב, שירות.
- לקוחות עסקיים ומוסדיים — ניסיון, אמינות, יכולת אספקה, מגוון גדול.

**הבידול:** המגזר המוסדי + מורשת משפחתית אמיתית משנות ה־30.
